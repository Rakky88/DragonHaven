Adventure event points now arrive when you claim the reward, with a trail of glowing sprites flying into a compact event bar. Journeys completed during an event remain eligible when claimed afterwards.

The bar uses each event's own artwork and chest sprite. Valentine invitations are integrated into the bar: choose an existing friend directly from a portrait list. Independently started Valentine test events now share points correctly.

Existing rewards and event schedules are preserved. Reduced-motion settings disable the flying particles.
