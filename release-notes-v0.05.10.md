# DragonHaven v0.05.10

- Finalizes five dragon-form sprites after in-device review, including the approved Everwyrm Spirit artwork and clean transparent cutouts.
- Makes Long Adventure timing gentler: each matching Expertise point now removes 15 minutes instead of one hour, with the existing one-day minimum retained.
- Enforces one seven-day Trial constellation contribution per calendar day, even when a completed constellation is claimed that same day.
- Keeps Wyrmling Ascension progress compact, with current level and XP shown only once and the separate total-Expertise requirement below it.
