## DragonHaven v0.05.34

- The friend invitation button now appears only during the active Valentine event.
- Background event synchronization no longer shows unrelated cloud warnings in Conclave. Invitations with a cloud-save conflict open the protected recovery choices.
- Trial Rankings show the three standard Trials and one illustrated event card. Naturally ended events remain available for three days; replaced or manually ended events disappear.
- Rankings scroll comfortably on smaller screens, with improved score placement for large text.

Existing progress and earned rewards are preserved. Update using DragonHaven.apk.
