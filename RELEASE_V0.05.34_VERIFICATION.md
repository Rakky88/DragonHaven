# v0.05.34 / 10084 verification

The active Valentine occurrence alone exposes friend invitations. Background
event synchronization no longer posts unrelated cloud errors in Conclave.
Foreground invitations with divergent saves open the guarded conflict chooser;
neither copy is silently overwritten. Recipients do not need an open event client.

The ranking selector contains the three standard Trials and one full-width
illustrated event card. Natural expiry retains results for exactly three days;
replacement or explicit ending retires the old choice across save reload.
Retirement does not discard earned points, partner contributions or chest claims.
An open ranking sheet expires its selected event and cached rows. Small displays
can scroll the controls, and large text moves scores beneath the keeper's name.
