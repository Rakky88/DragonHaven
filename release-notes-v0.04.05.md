# DragonHaven v0.04.05

- Mythical Chests now open with a longer, original ascension fanfare that exceeds every lower chest tier in scale and intensity.
- Sinister Chests now answer the reveal with an original low, cavernous evil laugh.
- Large egg collections use a compact multi-column inventory with newest-first ordering and a focused detail/action sheet.
- My Dragons can switch between the gallery and a compact list, and can be ordered by name, received date or rarity.
- Maximum Expertise scores now display the MAX artwork in My Dragons details.
- Ruin Breaker prominently shows remaining attempts; its power bar fades for one second before the spinning result and reward.
- A wrong Runeweaver choice glows red for one second before the spinning result and reward.
- Cavern Flight freezes its collision for a quarter-second, then sends the dragon through a clear upward-and-downward crash arc before the result and reward.
- Wooden Chests no longer contain gems.
- The visible in-game version, updater version, Android package version and release tag are synchronized, with a regression test preventing future drift.

No Supabase schema change is required for this release. The mandatory linked-production preflight is run immediately before publication.
