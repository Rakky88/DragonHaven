# DragonHaven v0.00.07

- Replaced the plain hatch countdown with a centered animated magical timer.
- Added 20 distinct achievement badge sprites. Locked badges are black
  silhouettes; unlocked badges reveal their full colors.
- Changed Achievements to one continuous list and added a persistent
  list/compact toggle. Compact mode shows only the badge collection.
- Added background-only Android notifications for newly unlocked achievements
  and dragon evolutions, including the achievement or dragon/form name.
- Alphabetized the language selector and gave it the same pinned handle and
  pull-down dismissal behavior as About DragonHaven.
- Added regression coverage for sprites, notification payloads, scrolling,
  compact layouts, language order, and both achievement layouts.
